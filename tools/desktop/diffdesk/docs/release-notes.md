# DiffDesk 1.0.0

First offline Windows build.

- Compare folders by size and timestamp. Content, hash, and text checks are optional.
- Compare and edit text, and merge three versions.
- Preview a sync, then execute that plan. Mirror deletes ask for confirmation.
- Compare JSON, XML, CSV, XLSX, images, binary files, and text extracted from PDF and DOCX.
- `DiffDesk.exe` opens the window. `diffdesk.exe` is the command line.
- The shippable build is a self-contained `win-x64` folder. It is not signed and it is not an installer.

Limits are in `known-limitations.md`. The 2,000-file measurement from this build is in `progress.md`.
